# Sales Data Cleaning and Analysis

## 📌 Project Overview

This project focuses mainly on cleaning and preparing messy sales data for analysis.

The dataset contained several real-world data quality issues such as inconsistent text formatting, typos, special characters, missing values, incorrect order totals, date formatting problems, and negative numerical values.

The main goal of this project is to demonstrate practical data cleaning skills using Python and Pandas. After cleaning the dataset, basic exploratory data analysis and visualizations were performed to extract meaningful business insights.

---

## 🎯 Main Focus of the Project

The main focus of this project is not advanced machine learning, but practical data cleaning and data preparation.

This project shows how raw and messy sales data can be transformed into a clean and analysis-ready dataset.

Key focus areas include:

- Cleaning messy categorical columns
- Standardizing text values
- Handling missing values
- Fixing numerical errors
- Recalculating incorrect order totals
- Preparing date columns for analysis
- Creating simple business insights through EDA and visualization

---
